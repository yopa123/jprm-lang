# Binarios de Release (v1.0.0-alpha)

Esta carpeta almacena localmente los ejecutables compilados y listos para ser adjuntados en las [GitHub Releases](https://github.com/yopa123/jprm-lang/releases).

> **Nota:** Todos los binarios (`.exe`, binarios Linux ELF, comprimidos) están excluidos de Git por el archivo `.gitignore` local para mantener el repositorio ligero y rápido de clonar.

## Contenido de la Versión Alpha

- **Windows:**
  - `JPRM-Setup-v1.0.0-alpha.exe` (Instalador oficial firmado mediante Authenticode).
  - `jprm.exe` (Binario portable CLI firmado para PowerShell / CMD).

- **Linux:**
  - `jprm` (Binario portable ELF x86_64 para distribuciones Linux modernas).
